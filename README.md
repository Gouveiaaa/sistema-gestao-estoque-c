# Sistema de Gestão de Estoque e Emissão de Vendas em C

Sistema desenvolvido em linguagem C para gerenciamento simples de estoque, controle de produtos e registro de vendas com cálculo de impostos fictícios (ICMS).

Funcionalidades
- **Cadastro de Produtos:** Registro com ID, nome, quantidade em estoque e preço unitário.
- **Listagem de Estoque:** Relatório formatado em tabela com todos os itens cadastrados.
- **Registro de Vendas:** Baixa automática no estoque e cálculo do valor total e estimativa de imposto (ICMS).

Tecnologias Utilizadas
- **Linguagem C**
- Conceitos aplicados: Structs, Arrays, Funções, Manipulação de Entrada/Saída e Lógica de Negócio.
